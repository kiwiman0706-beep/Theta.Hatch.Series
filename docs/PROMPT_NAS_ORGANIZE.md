# NAS の整理をローカルの Claude Code に頼む文

自分の PC（Windows）で動く Claude Code に貼る。NAS の共有フォルダをネットワークドライブとしてつないでおく。
1 回で全部やろうとせず、**種類を 1 つ・フォルダを 1 つ**ずつ頼む（例：「まず music の 洋楽 だけ」）。

---

NAS（Synology DS1825+）のメディアを整理したいです。手伝ってください。

## 決まり

GitHub の `kiwiman0706-beep/Theta.Hatch.Series`（公開）の **`spec/THETA_LIBRARY_SPEC.md`** に、並べ方と名前の付け方、整理の約束（§7）が書いてあります。まずこれを読んでください。映画・ドラマは、そこから参照している `kiwiman0706-beep/Theta.Movie.Hatch` の `docs/naming-convention.md` に従います。

今回の対象：**＜例：`\\NAS\music\` の 洋楽 フォルダ＞**（ネットワークドライブ `M:` につないであります）

## 進め方

1. **調べる**：対象のフォルダを読むだけで調べ、件数・形式・今の並び方・問題（名前のゆれ、タグの欠け、重複、文字化け、NFD の名前など）をまとめて見せてください。まだ何も動かさないでください。
2. **スナップショット**：DSM で対象の共有フォルダのスナップショットを撮るよう、私に頼んでください（私が撮ります）。
3. **変更案**：`spec` の形に合わせた変更案を CSV（今の場所・新しい場所・直すタグ・理由・確かさ）で作り、要点を表で見せてください。確かさの低い物は「要確認」にして、私に聞いてください。
4. **実行**：私が OK した物だけ、1 回数百件までで動かしてください。動かしたことは `_整理の記録/<日時>.csv` に残し、元に戻すスクリプトも一緒に作ってください。
5. **確かめる**：終わったら件数が合っているか（消えた物が無いか）を確かめ、Jellyfin の再スキャン・Synology Photos の再インデックス・Book の索引の作り直しが要るかを教えてください。

## 守ってほしいこと

- **消さない**。重複や不明な物は `_未整理/` か一覧に回す。
- 中身を変えない（再エンコード・形式の変換をしない）。直してよいのは音楽のタグと写真の XMP だけで、それも変更案で確認してから。
- Synology Photos のスマホのバックアップ先（`MobileBackup/` など）と、Book の `_DSBooksCache`・`_DSBooksSync` は動かさない。
- 道具は Python 3.12 で（音楽のタグは `mutagen`、写真の EXIF・XMP は `exiftool` か Pillow、動画は `ffprobe`）。入っていない物は入れ方を教えてから使ってください（Windows は winget）。
- 大きな処理は、まず 10 件くらいで試して結果を見せてから。
