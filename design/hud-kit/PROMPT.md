# ほかの Hatch アプリに当てるときの指示文

そのアプリのリポジトリを開いた Claude Code の会話で、このキット（zip）を渡して、下の文を貼ってください。

---

このアプリの見た目を、添付の「Theta Hatch HUD デザインキット」に合わせてください。

- まず README.md と design-tokens.json を読み、決まり（オレンジ 1 色・角を丸めない・線 1dp・Oswald と Share Tech Mono・英字の小さなラベル・一覧は縞模様・ダークとライト）を確認する
- Compose のアプリなら compose/ の Kotlin（パッケージと R の import を合わせる）と書体を入れ、画面を HudTheme で包み、既存の部品を HudBits の部品に置き換える。View（XML）のアプリなら views/res を入れて Theme.Hatch.Hud と Hud.* の style を当てる
- 機能や画面の流れは変えない。見た目（色・書体・余白・角・線・ラベル）だけを変える
- テーマは「ダーク・ライト・端末に合わせる」を選べるようにする（設定がなければ端末に合わせる）
- 書体のライセンス（licenses/）をアプリに同梱する
- 変更前と変更後の画面を見比べられるようにして、ビルドとテストが通ることを確かめてから報告する
