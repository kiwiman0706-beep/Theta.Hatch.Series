# Theta Hatch シリーズ NAS ライブラリ整理規則 v0

> 正本はこのリポジトリ（kiwiman0706-beep/Theta.Hatch.Series の `spec/`）。2026-11-08 作成。

NAS（Synology DS1825+）に置いた**映画・音楽・写真・本**の並べ方と名前の付け方。
今のアプリ（Movie・Music・Photo・Book）が読める形で、しかも**アプリが無くなっても Jellyfin・Plex・Kodi・Synology Photos・Calibre・Obsidian などでそのまま読める**形にする。整理は Claude（ローカル）に任せる前提で、その約束も書く（§6）。

## 1. 共有フォルダ

| 共有フォルダ | 中身 | 読むもの |
| --- | --- | --- |
| `video` | 映画・ドラマ・アニメ・テレビ録画・ライブ・ホームビデオ | Jellyfin（Theta Movie Hatch）、TV |
| `music` | 音楽 | Theta Music Hatch（Audio Station・WebDAV）、Jellyfin |
| `photo`・各自の `Photos` | 写真・スマホの動画 | Synology Photos、Theta Photo Hatch、Mitene |
| `book` | 電子書籍・自炊 PDF・漫画・オーディオブック | Theta Book Hatch |
| `Obsidian` | Theta Vault（ノート）。作品のメモ・索引はここ | 各アプリ、Obsidian（`THETA_VAULT_SPEC.md`） |

- 名前は**実際の共有フォルダ名に合わせて直す**（未確認）。メディアは Vault にコピーせず、Vault のノートから NAS のパスで参照する。

## 2. 全部に共通の名前の決まり

`Theta.Movie.Hatch` の `docs/naming-convention.md` §8 と同じ。

- Windows・SMB で使えない文字は全角に（`:`→`：` `?`→`？` `/`→`／` `*`→`＊` `"`→`”` `<>`→`＜＞` `|`→`｜` `\`→`＼`）。名前の最後にスペースや `.` を置かない、先頭に `.` を置かない。
- Unicode は **NFC** にそろえる（Mac で作った名前の濁点が分かれていたら直す）。
- ファイル名は 120 文字以内（暗号化した共有フォルダなら 47 文字くらいまで）。
- **元のファイルの中身は変えない**（再エンコード・形式の変換をしない。タグ・メタデータを直すのは音楽と写真だけ、§4・§5）。
- 詳しい情報はファイル名に詰め込まず、**付属ファイル（`.nfo`・`.xmp`・`.md`）とタグ**に書く。

## 3. 映画・ドラマ（`video`）

**Theta Movie Hatch の `docs/naming-convention.md` をそのまま使う**（Jellyfin・Kodi・Plex 共通の形）。要点：

```
video/
├─ 映画/君の名は。 (2016)/君の名は。 (2016).mkv
├─ アニメ映画/…
├─ ドラマ/〇〇 (2019)/Season 01/〇〇 S01E03「サブタイトル」 [2019-04-21 TBS].ts
├─ アニメ/〇〇 (2019)/Season 01/〇〇 S01E01「サブタイトル」.mkv
├─ テレビ/〇〇の番組 (2005)/Season 2019/〇〇の番組 2019-04-07「今回の内容」 [テレ朝].ts
├─ ライブ/…
└─ ホームビデオ/2024/2024-08-12 海水浴.mp4
```

- フォルダ 1 つ＝作品 1 つ、`タイトル (年)`、話数は `S01E03`、補足は末尾の `[ ]`。
- 作品の情報は `.nfo`、ポスターは `poster.jpg`。
- スマホで撮った家族の動画は**写真と一緒（§5）**。カメラで撮って編集した物・まとまった物だけ `ホームビデオ/`。

## 4. 音楽（`music`）

```
music/
├─ <アルバムアーティスト>/
│  └─ <アルバム> (<年>)/
│     ├─ 01 <曲名>.flac            ← ディスク 1 枚
│     ├─ 1-01 <曲名>.flac          ← 複数ディスクなら「ディスク-トラック」
│     └─ cover.jpg                 ← ジャケット（500px 以上の正方形）
├─ Various Artists/<アルバム> (<年>)/…   ← オムニバス・サントラ
└─ _プレイリスト/<名前>.m3u8
```

- **正本はタグ**（ファイル名・フォルダ名はタグから作る）。Theta Music Hatch・Audio Station・Jellyfin はタグを読む。
- タグは ID3v2.4（MP3）・Vorbis Comment（FLAC）・iTunes タグ（M4A）で、**UTF-8**。Shift_JIS の古い ID3 は UTF-8 に直す。
- 必ず入れるタグ：曲名・アーティスト・**アルバムアーティスト**・アルバム・年・トラック番号・ディスク番号・ジャケット（埋め込みか `cover.jpg`）。オムニバスはアルバムアーティストを `Various Artists`。
- アーティスト名のゆれ（全角・半角、「The」の有無）は 1 つにそろえる。読みは `ARTISTSORT`・`ALBUMSORT`。
- アルバム・アーティストのメモは Theta Music Hatch が Vault に書き出す（`Obsidian/…/Music/`）。

## 5. 写真・スマホの動画（`photo`・`Photos`）

```
photo/
├─ <年>/
│  └─ <YYYY-MM-DD> <イベント>/
│     ├─ 20240812_103512_海水浴_PXL_20240812_013512345.jpg
│     ├─ 20240812_103512_海水浴_PXL_20240812_013512345.xmp   ← HEIC・動画のときだけ（JPEG は中に埋め込む）
│     └─ …
└─ _未整理/          ← 日付・イベントが決められなかった物（消さない）
```

- 名前は **Theta Photo Hatch と同じ**：`<撮影日時 YYYYMMDD_HHMMSS>_<イベント>_<元のファイル名>.<拡張子>`。元の名前を残すので、どのスマホ・カメラの物か分かる。
- 撮影日時は EXIF（動画はメタデータ）から。無ければファイルの更新日時で、`_未整理/` に。
- 分類・イベント名・★・キーワードは **XMP** に（JPEG は埋め込み、HEIC・動画は同じ名前の `.xmp`）。Synology Photos・Lightroom・digiKam が読める。
- **Synology Photos のスマホのバックアップ先（`MobileBackup/` など）は動かさない**。バックアップが重複して上がり直すおそれがあるため（未確認）。整理するのは、すでに取り込み済みの物か、別の場所のコピー。
- 同じ写真の重複は、中身のハッシュで見つけて一覧に出すだけ（消さない）。

## 6. 本（`book`）

```
book/
├─ 漫画/<作者>/<シリーズ名>/<シリーズ名> 第01巻.pdf
├─ 小説/<作者>/<書名>.epub
├─ 小説/<作者>/<シリーズ名>/<シリーズ名> 第01巻.epub
├─ 技術書/<分野>/<書名>.pdf
├─ 雑誌/<誌名>/<誌名> 2024-05.pdf
├─ 写真集・画集/<作者>/<書名>.pdf
└─ オーディオブック/<作者>/<書名>.m4b
```

- 作者は「姓 名」（例 `村上 春樹`）。複数なら 1 人目。巻は 2 けた（`第01巻`、100 巻を超えるシリーズは 3 けた）。
- **同じ本の別の形式は、同じ名前にして同じフォルダに置く**（例 `〇〇.epub` と `〇〇.m4b`）。Theta Book Hatch が 1 つの作品にまとめる（`Theta.Book.Hatch` の `docs/DATA_AND_SYNC.md`）。
- 自炊の `.jisui` と原本 PDF は同じ名前で隣に（`.jisui` の `pdf.sidecar`）。
- **`_DSBooksCache`・`_DSBooksSync` は動かさない・消さない**（Book のキャッシュと読書位置）。
- 本を動かすと、Book は中身のハッシュで新しい場所を見つける。**整理の前後に、Book の PC ツールで索引を作り直す**（読書位置・栞を失わないため）。

## 7. Claude に整理を任せるときの約束

`naming-convention.md` §10 と同じ。どの種類でも：

1. **始める前に Btrfs のスナップショット**を撮る（DSM の Snapshot Replication）。
2. まず **変更案の一覧（CSV：今の場所・新しい場所・理由・確かさ）** を作る。確かさの低い物は `要確認`。
3. 利用者が確認して OK を出した物だけ動かす。**1 回は数百件まで**、種類ごと・フォルダごとに。
4. 動かしたことはすべて記録し（`_整理の記録/<日時>.csv`）、**1 つのコマンドで元に戻せる**ようにする。
5. **消さない**。重複・不明な物は `_未整理/` や一覧に回す。
6. 中身を変えない（再エンコードしない）。直してよいのは音楽のタグと写真の XMP だけ、それも一覧で確認してから。
7. 整理が済んだら、Jellyfin の再スキャン、Synology Photos の再インデックス、Book の索引の作り直しを行う。

作業は、NAS の共有フォルダを PC にネットワークドライブとしてつなぎ、ローカルの Claude Code で行う（依頼文：`docs/PROMPT_NAS_ORGANIZE.md`）。
